# Utkast som ikke lastes av spillet

`trener-genius-utkast.json` holder svaralternativene (tre feil svar), kategorien og
faktalinjen for hvert spørsmål i `data/source/trenerquiz.json`. Når Wikipedia-kontrollen
har godkjent et spørsmål, flyttes utkastet til `data/source/trener-genius.json` med
artikkelen som kilde. Bare det som står der, kan spilles i Trainer-Genie.
